# Rui Yan — Research Homepage

Personal research homepage: https://yanrui27.github.io/

A responsive, bilingual (English / Chinese) static page. No build step or dependencies.

## Update

Edit `index.html`. Publication metadata, author order, descriptions, and links are written directly in the HTML. Update both language versions when changing copy. The language switch is handled by a small script at the end of the page. Long author lists expand with native HTML details controls.

The research list covers all 13 entries from the owner's Google Scholar export dated 3 November 2026, including model releases and a collectively authored research project. Citation metrics are a dated snapshot (1,097 citations; h-index 8; i10-index 8), not a live feed. No account metadata or raw exported profile HTML is included.

DAPO is listed as NeurIPS 2025 following the official proceedings, which differ from the export's 2026 year. Its conference author list is used for the conference record.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/.
