# Rui Yan — Research Homepage

Personal research homepage: https://yanrui27.github.io/

A responsive, bilingual (English / Chinese) static page. No build step or dependencies.

## Update

Edit `index.html`. Publication metadata, author order, descriptions, and links are written directly in the HTML. Update both language versions when changing copy. The language switch is handled by a small script at the end of the page.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/.

## Hosting

GitHub Pages: deploy from branch `main`, folder `/ (root)`.
